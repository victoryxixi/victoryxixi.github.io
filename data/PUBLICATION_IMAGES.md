# Publication image replacement

Upload your graphical abstracts to [images/publications](../images/publications). Each paper has a stable numeric ID shown below.

Edit [publication-images.json](publication-images.json) to point the matching ID at the uploaded PNG, JPG, WebP or SVG. Example: replace ID 16's value with `/images/publications/paper-16.png` after uploading that file. Keep all other entries unchanged. The website reads this JSON directly when opened; no build or HTML editing is needed. Wait for GitHub Pages to deploy, then refresh the site.

Current SVG files are illustrative placeholders. An uploaded graphical abstract replaces the placeholder.
